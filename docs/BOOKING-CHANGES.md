# 预约平台改进记录

## 2026-10-19：清理与正确性修复

本地根目录清除了旧环境文件、Python 虚拟环境、临时浏览器记录和无关 PDF。本地与远端秒杀分支均已删除，main 保留预约平台，optimization 分支保留。

创建预约统一按“用户行 → 设备行”加锁，修复跨设备的用户配额竞争，并使同用户相同 requestKey 的跨设备竞争返回明确的业务冲突。其他设备变更路径不获取用户行锁，避免反向锁顺序。

修正缺失查询参数、资源不存在、请求方法和 Content-Type 的 HTTP 状态；新增 SVG favicon；时段查询改为精确比较七天时长。

验证：38 项 H2 集成测试通过，包含新增的跨设备配额、跨设备幂等键竞争与 HTTP 边界测试。

## 调度与通知治理

维护任务使用设备 ID 游标，每轮最多处理 100 台有候补或到期任务的设备，跳过空闲设备。新增到期索引、调度耗时、管理员运行指标与失败事件接口。

通知按单事件事务投递，失败指数退避，五次失败后隔离；其他事件不受单条坏消息影响。管理员可手动重试，重试操作独立审计。新增 Flyway V2，已有数据库自动升级。

验证：41 项 H2 集成测试通过，包括真实数据库约束注入的坏消息、退避/隔离/人工重试、分页候选与管理权限。
